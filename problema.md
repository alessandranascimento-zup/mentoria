# Problema que vamos resolver

## Intruções do problema
- Categorize emails recebidos em Reclamação, Solicitação e Elogios

- Cada categoria tem um tratamento diferente, deve se configurar uma ação para cada tipo.

- A cada ação deve ter um encaminhamento de notificacao para os envolvidos na requisição do email

- A maior parte do processo deve ser autônomo

- Ter a possibilidade de gerar um relatório com indicadores de atendimentos autônomos

	- Tempo de atendimento

	- categorização com falha

	- retentativas

	- chamados que caiu para um atendimento humano


## Requisitos

- Os e-mails devem ser uma base de dados ficticios (csv ou json ou txt), com os seguintes dados: from, to, cc, subject, date-time, content;
